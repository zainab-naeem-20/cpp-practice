## 📖 Topics & Learning Roadmap

### ⚡ 1. C++ Basics
- 🔹 Variables, Data Types & Operators
- 🔹 Conditional Statements (`if-else`, `switch`)
- 🔹 Loops (`for`, `while`, `do-while`)
- 🔹 Functions & Recursion
- 🔹 Pointers, References & Dynamic Memory Allocation

### 🧱 2. Object-Oriented Programming (OOP)
- 🔹 Classes & Objects
- 🔹 Constructors & Destructors
- 🔹 Encapsulation & Data Hiding
- 🔹 Inheritance (Single, Multiple, Multilevel, Hierarchical)
- 🔹 Polymorphism (Compile-time & Run-time)
- 🔹 Abstraction & Virtual Functions

### 💡 3. Data Structures & Algorithms (DSA)
- 🔹 **Arrays & Strings:** Traversal, Two-Pointer, Sliding Window
- 🔹 **Linked Lists:** Singly, Doubly, and Circular
- 🔹 **Stacks & Queues:** LIFO/FIFO operations, Monotonic Stack
- 🔹 **Trees & Graphs:** Binary Trees, BST, DFS & BFS Traversal
- 🔹 **Sorting & Searching:** Binary Search, Bubble, Selection, Merge & Quick Sort
